# 診所資料庫管理系統

這是資料庫課程的期末專案，以診所的病患、就診及人員工作資料為主題，設計資料表並製作查詢介面。專案使用 SQL Server 儲存資料，並以 Python 的 Tkinter 製作圖形介面，透過 pyodbc 連接資料庫。

## 資料庫設計

資料庫包含六個資料表：

- `Patients`：病患基本資料
- `Staffs`：員工資料
- `Visits`：病患就診紀錄
- `Prescriptions`：就診時開立的處方
- `Tasks`：工作任務
- `Task_Assignments`：任務指派與處理狀態

資料表之間使用主鍵與外鍵建立關聯，並對部分欄位設定限制，例如病患 Email 的唯一性、處方天數及任務狀態。

## 系統功能

Python 介面可以新增病患資料，也提供病患基本資料、指定年份後出生的病患、姓王的病患、病患就診紀錄、員工建立的任務，以及就診處方內容等查詢。查詢結果會顯示在程式視窗中。

專案另外使用 SQL Server 的預存程序與檢視表整理查詢邏輯，並準備範例資料展示資料表之間的關係與查詢結果。

## 檔案說明

- `創建表格的程式碼.txt`：建立資料庫與六個資料表。
- `建立查詢所用的程式碼.txt`：建立預存程序與檢視表。
- `增加demo資料的程式碼.txt`：加入展示用的範例資料。
- `GUI.py`：新增病患與執行查詢的圖形介面。

## 執行注意事項

此專案需要 SQL Server、Python、`pyodbc`，以及 SQL Server ODBC Driver 17。`GUI.py` 目前連接的伺服器名稱是 `NINI`；在其他電腦執行時，需要將連線設定改為該電腦的 SQL Server 名稱。

**注意：**建立表格的程式碼會先刪除已存在的 `ClinicDB3` 資料庫，再重新建立。執行前請確認其中沒有需要保留的資料。
